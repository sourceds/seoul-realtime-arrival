# seoul-realtime-arrival
wrapper/library for fetching arrival information from Seoul's public transportation APIs.

서울특별시 및 수도권 지역의 버스 및 지하철 API 접근을 위한 wrapper입니다. 


## Python Dependencies / 필수 패키지
- [Requests](https://pypi.org/project/requests/) `pip install requests`

## Prerequisites / 필수 사항
For this program to work, you must have access to Seoul's bus/metro APIs.
- Access to the Metro API can be obtained via [Seoul's Open Data Hall (서울열린데이터광장)](https://data.seoul.go.kr/dataList/OA-12764/F/1/datasetView.do)
- Access to the Bus API can be obtained via [Public Data Portal (공공데이포털)](https://www.data.go.kr/data/15000314/openapi.do)

프로그램이 동작하기 위해서는 서울시 버스 및 지하철 API에 접근 권한이 있어야 합니다.
- 지하철 API의 경우 [서울열린데이터광장](https://data.seoul.go.kr/dataList/OA-12764/F/1/datasetView.do)에서 API 키를 획득할 수 있습니다.
- 버스 API의 경우 [공공데이포털](https://www.data.go.kr/data/15000314/openapi.do)에서 API 키를 획득할 수 있습니다.
